# 挑水果

用手機鏡頭對準水果或蔬菜，即時辨識是哪一種，並顯示挑選技巧。辨識全部在手機瀏覽器內完成（MobileCLIP + Transformers.js），不需要付費 API，也不會上傳照片。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html`、`style.css`、`app.js` | 網頁本體 |
| `fruits.js` | 51 種水果、66 種蔬菜的挑選技巧與給 CLIP 比對的英文描述 |
| `embeddings-s1.json`、`refs-s1.bin` | 主模型（MobileCLIP-S1）的分類向量與參考樣本（約 4,300 張真實照片的影像特徵，int8 約 2.2MB） |
| `embeddings.json`、`refs.bin` | 輕量備援模型（MobileCLIP-S0）的同類檔案，網頁曾被瀏覽器強制關掉時改用 |
| `tools/` | 產生上述檔案的腳本（見下方「新增或修改蔬果」） |

## 本機預覽

```bash
python tools/serve.py
```

電腦開 http://localhost:5500 即可（這個伺服器關閉了快取，改完程式重新整理就會生效）。手機要開相機，網址必須是 **https**，所以要部署到 GitHub Pages、Cloudflare Pages、Vercel 或 Netlify 這類免費的靜態網站服務（把整個資料夾上傳即可，不需要 `tools/`）。

## 新增或修改蔬果

1. 編輯 `fruits.js`（水果放 `FRUITS`、蔬菜放 `VEGETABLES`；`names` 用英文描述外觀，越具體越好；`cue` 是二選一時顯示的外觀重點）
2. 在 `tools/` 依序執行（兩個模型都要做；`MODEL=s1` 是主模型）：

   ```bash
   npm install
   node build-embeddings.mjs && MODEL=s1 node build-embeddings.mjs   # 文字特徵
   node collect-photos.mjs                                           # 從維基共享資源下載照片到 tools/photos/（不進 git）
   node embed-photos.mjs && MODEL=s1 node embed-photos.mjs           # 照片的影像特徵（原圖＋中央裁切）
   MODEL=s1 node train.mjs --write                                   # 主模型：原有品項比線上版本準才寫入
   node train.mjs --quick --write --force                            # 輕量備援模型：跟主模型同一份品項
   ```

   `train.mjs` 會印出每個新品項在測試集的準確度；太低的（約 55% 以下）建議從 `fruits.js` 拿掉再重跑。

## 備註

- 主模型是 MobileCLIP-S1（fp16 約 43MB）。輕量版 S0 約 23MB。第一次開啟時下載，之後由瀏覽器快取。兩者的 q8／uint8 量化版本辨識結果都不可靠，所以用 fp16。
- 認錯時，點候選或用「手動選蔬果」選正確答案，App 會把當下畫面記在這支手機的 localStorage，之後遇到類似畫面會更準。
- 準確度：維基共享資源約 9,600 張照片，依檔名固定分成訓練 50%／驗證 20%／測試 30%；訓練時另加每張照片的中央 70% 裁切（模擬 App 對準框）。哪些照片有效、怎麼分組一律由 S0 判斷，所以不同模型是在同一批照片上比較。
  - 原有 107 種（1,636 張測試照片）：前一版（S0）75.1% → 目前（S1）**79.0%**，多角度辨識 **79.5%**；正確答案在前兩名 86.7% → **88.6%**。
  - 這次新增的 10 種：130/158（82%）。
- 多角度辨識：即時模式輪流看「整個對準框」與「框中央 70%」，由平滑機制合併；照片模式兩種都算再平均特徵。
- 前兩名分數接近（差距 < 0.3）時改成讓使用者二選一：測試集上約 15% 的照片會詢問，「直接給錯答案」約 12%。
- 測試照片和訓練照片同樣來自維基共享資源，實際用手機鏡頭拍的提升幅度可能會小一些。
- 比較容易混淆的組合：檸檬和金桔；藍莓、黑莓和桑椹；蜜棗和青梅；大白菜、青江菜和萵苣；苦瓜和絲瓜；地瓜和馬鈴薯；芋頭和山藥；大番茄和小番茄。香蕉、芒果、鳳梨、青花菜、茄子、洋蔥這類很穩定。
- 測試後沒有加入：菠菜（7/15）、韭菜（6/12，還會讓青蔥被認錯）、芥藍（2/12）、豌豆苗（1/4）。
- 手機瀏覽器可能因記憶體不足或切到背景而關掉網頁。App 會自動重新開啟相機；若判斷是異常關閉，會改用輕量模型與 CPU 模式（狀態列顯示「辨識中・輕量」）。辨識結果穩定後也會自動降低辨識頻率，減少發熱。
